# Governance

## Scope

The toolkit collects and organizes evidence for website conversion experience, search readiness and AI-discovery experiments. It does not certify security, guarantee ranking or measure conversion without first-party data.

## Change control

Changes to network safety, crawler interpretation, evidence labels, report claims or prioritization require tests and pull-request review.

## Evidence integrity

Findings must retain source, status, confidence and scope. Presentation layers may summarize but must not manufacture an overall score.

## External actions

Form submission, authenticated access, crawler-policy changes, production edits and checkout require explicit authorization outside the default audit workflow.

## Updates

The canonical repository may be checked for new public versions. No silent update, remote-script execution or overwrite of local changes is allowed.
